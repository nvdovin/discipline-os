# Discipline OS — дизайн-бриф

Статус: утверждён для MVP.
Дата: 22.11.2026.
Источник токенов: `app/static/css/app.css` (`:root`).

## 1. Продукт и аудитория

Discipline OS — личный помощник одного пользователя: сон, движение, питание,
чтение Библии и одно главное дело дня. Основной сценарий — Telegram Mini App
на телефоне утром и вечером, вторичный — тот же интерфейс в браузере на
планшете и десктопе.

Ключевая эмоция: спокойный контроль без чувства вины. Приложение показывает
факты и следующий шаг, а не «мотивационные» лозунги и не штрафы за пропуски.

Принципы:

1. Один экран — один главный вопрос: «что сейчас важно?».
2. Один primary CTA на экран или секцию; остальные действия вторичны.
3. Данные честные: если значения нет — прочерк или приглашение записать,
   а не выдуманное число.
4. Тёмная тема по умолчанию, мобильный first, крупные touch-зоны.
5. Русский язык интерфейса и бота, короткие фразы, без канцелярита.

## 2. Визуальный язык

### Цветовые роли

Все значения уже живут в `:root` как семантические токены. Компоненты
используют только `var(--token)`, hex-значения вне `:root` запрещены.

| Токен | Роль |
| --- | --- |
| `--color-bg` | фон приложения |
| `--color-bg-elevated` | фон верхнего уровня |
| `--color-surface` | карточки и панели |
| `--color-surface-raised` | вложенные акцентные панели |
| `--color-surface-soft` | поля, чипы, неактивные зоны |
| `--color-border` / `--color-border-strong` | разделители и границы |
| `--color-text` | основной текст |
| `--color-text-soft` | вторичный текст |
| `--color-muted` | подписи, hint, метаданные |
| `--color-accent` | действия, фокус, прогресс |
| `--color-accent-strong` | hover/active акцента |
| `--color-accent-contrast` | текст на акцентной кнопке |
| `--color-success` | выполнено, хорошая динамика |
| `--color-warning` | внимание, незавершённое |
| `--color-info` | нейтральная информация |
| `--color-danger` | удаление и ошибки |
| `--color-focus` | focus-visible ring |
| `--color-accent-soft` и другие `*-soft` | тонированные подложки |

Правила:

- акцент — только для действия, фокуса и прогресса, не для декора;
- опасные действия — `--color-danger`, подтверждение обязательно;
- контраст текста и интерактивных элементов — не ниже WCAG AA;
- новые оттенки не добавляются без роли и записи в этом брифе.

### Типографика

- Семейство: `--font-sans` (системный стек SF Pro / Segoe UI / Roboto).
- Числа и метрики: `--font-mono` только для табличных значений.
- Иерархия: заголовок экрана → крупная метрика hero → заголовок карточки →
  тело → hint. Не более трёх размеров в одной карточке.
- Длинный текст — 45–75ch, переносы `overflow-wrap: anywhere` для ссылок.
- Все тексты интерфейса — на русском, без англицизмов там, где есть
  понятный русский термин.

### Отступы, радиусы, тени

- Шкала отступов: `--space-1` … `--space-8` (4–40 px). Случайные значения
  запрещены.
- Радиусы: `--radius-sm` … `--radius-xl`, `--radius-full` для чипов.
- Тени: `--shadow-card` и `--shadow-float`; градиенты — только
  `--gradient-hero` / `--gradient-ambient` как фон, не как декор кнопок.

## 3. Сетка и адаптив

- Контейнер: `.app-shell`, максимум 1120 px, центрирован, боковые отступы
  одинаковые.
- Мобильный: одна колонка, нижняя навигация 64 px (`--nav-height`),
  контент не уходит под неё.
- 560 px+: карточки могут становиться в 2 колонки.
- 768 px+: двухколоночные сетки для связанных блоков, навигация остаётся
  нижней (привычный мобильный паттерн Mini App).
- 960–1280 px+: контент не растягивается на всю ширину, длинный текст
  ограничен, save-bar настроек — не шире 420 px.
- Проверяются 375, 768 и 1440 px. Горизонтальный скролл — 0.

## 4. Экраны и иерархия

| Экран | Главный вопрос | Primary CTA |
| --- | --- | --- |
| Сегодня | Что важно сегодня? | Отметить привычку / записать итоги |
| Тренировка | Что делать по плану? | Добавить подход |
| Питание | Что съел и сколько выпил? | Записать приём пищи |
| Сон | Как прошлая ночь? | Записать / изменить сон |
| Статистика | Есть ли динамика? | Переключить неделю/месяц |
| Настройки | Подстроить систему? | Сохранить |

На каждом экране: заголовок с датой/контекстом, один hero-блок с ключевой
метрикой, затем карточки деталей. Пустые состояния объясняют следующий шаг
и не выглядят как ошибка.

## 5. Компоненты и состояния

Обязательные варианты дизайн-системы:

- Button: primary / secondary / ghost / danger; default, hover,
  focus-visible, active, disabled, loading.
- Input, textarea, select, file: label, hint, error, disabled,
  focus-visible. Нативный внешний вид не допускается; `select` и
  `input[type=file]` — только в стилизованной обёртке.
- Card, pill, stat, progress ring, tabs/segmented control, modal sheet,
  toast, empty state, skeleton, bottom navigation.
- Иконки: SVG с `aria-hidden="true"` или доступным именем.
- Sheet: role="dialog", aria-modal, focus trap, Escape, возврат фокуса,
  блокировка фонового скролла.

Состояния данных:

- loading — skeleton, не пустой экран;
- empty — объяснение и действие;
- error — текст рядом с блоком, кнопка повтора, без `alert()`;
- success — toast + обновление метрики;
- disabled — понятная причина, не только серый цвет.

## 6. UX и доступность

- Touch target ≥ 44×44 px; нижняя навигация — 64 px.
- Tab-порядок совпадает с визуальным; Escape закрывает sheet; фокус
  возвращается на кнопку-триггер.
- Ошибки форм связаны с полем через `aria-describedby`, текст на русском.
- Деструктивные действия — подтверждение; опасные — явная пометка.
- `prefers-reduced-motion` отключает анимации.
- Контраст — WCAG AA; focus-visible виден на тёмном фоне.
- Числовые поля с дробями — `inputmode="decimal"`, принимают запятую.
- Даты и время — в локальном часовом поясе пользователя.

## 7. Контент и тон

- Коротко, по делу, без давления: «Сегодня 3 из 5», «Можно начать с минимума».
- Не выдумывать калории, белок, вес и длительность: пустое значение
  остаётся пустым.
- Пропуск не называется провалом; streaks не наказывают, а показывают
  последовательность.
- Заголовки — с заглавной буквы, без CAPS LOCK и лишних восклицаний.

## 8. Критерии дизайн-приёмки

- [ ] Нет hex-значений вне `:root` и inline-цветов.
- [ ] Нет нативных `select` / `input[type=file]` без стилизации.
- [ ] Нет кнопок без класса/варианта дизайн-системы.
- [ ] Нет `outline: none` без focus-visible замены.
- [ ] Все интерактивные зоны ≥ 44 px.
- [ ] 375 / 768 / 1440: горизонтальный скролл 0, ничего не обрезано,
      интерактивные элементы не налезают друг на друга.
- [ ] Один primary CTA на экран/секцию.
- [ ] Длинный текст не растянут на всю ширину.
- [ ] Sheet закрывается Escape и возвращает фокус.
- [ ] Пустые, загрузочные и ошибочные состояния выглядят завершёнными.
- [ ] Скриншоты и DOM-метрики приложены к ревью.
